# Christmas Tree Packing Algorithm

Algoritmo de optimización para empaquetar árboles de Navidad usando Simulated Annealing.

## Características

- Algoritmo de Simulated Annealing para optimización
- Visualización en tiempo real del proceso
- Generación de videos del proceso de optimización
- Modo de compactación inteligente
- Detección y resolución de colisiones

## Instalación

```bash
pip install shapely matplotlib imageio imageio-ffmpeg numpy Pillow
```

## Uso

```bash
python app/main.py
```

## Estructura

- `app/`: Código principal de la aplicación
  - `algorithms/`: Algoritmos de optimización
  - `models/`: Modelos de datos
  - `evaluation/`: Evaluación de costos
  - `visualization/`: Visualización
- `create_video.py`: Script para crear videos desde frames
- `run.py`: Punto de entrada alternativo
